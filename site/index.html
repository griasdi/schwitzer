Humans decide. Agents work.

Every task walks the same short path. Agents do the work in between; the decisions are buttons only people can press.

  1. Idea
    humanagent

    Anyone notes it: /schwitzer idea in a terminal or + in the app.

  2. Proposed
    agent

    An agent drafts it with /schwitzer propose and asks you before it sends.

    Accept
  3. Accepted
    human

    A person presses Accept. Now it waits for a plan.

  4. Plan ready
    agent

    An agent claims it with /schwitzer plan and hands in its plan.

    Approve
  5. Approved
    human

    A person approves the plan. An agent waiting on its plan review starts building.

    Pick
  6. Building
    agent

    An agent claims it with /schwitzer build, or you pick it for your own agent.

  7. Done
    agent

    The agent finishes it with a note on what it did.

Reject, replan and reopen are buttons too. No agent ever gets them.

Lives in your agent.

Link a repository to a project and the app installs the omp plugin there. Your agent gets /schwitzer and a set of tools; it talks to your own app over a local MCP server, loopback only, behind a token.

/schwitzer plan
Claim an accepted task and plan it in plan mode.
/schwitzer build
Claim an approved task and build it.
/schwitzer propose
Draft a proposal, ask you, then send it.
/schwitzer idea
Note an idea right away, without an agent turn.

A room in two clicks. No accounts.

  1. 1Create a room: paste a server URL, name the room.
  2. 2Share the room key. Whoever has it joins.
  3. 3Link your repositories to the room's projects.

Public server

Open rooms on our server right away. It stores your room's tasks; run your own if you'd rather keep them.

weida://sha256:b4e7d073f1bc6e0c663202055c74bfbd703aa83eadc79d58c55d5d9934b3e4cc@stkn.org:7444

Your identity is a key on your machine. There is nothing to sign up for.

Run your own

The server is one binary that speaks QUIC over UDP. Releases ship it for Linux; elsewhere, build it from source.

cargo build --release -p schwitzer-server
target/release/schwitzer-server --listen 0.0.0.0:7444 \
  --public-host <name clients dial> --data-dir <dir>

It prints its weida:// URL on start. Server guide in the README
